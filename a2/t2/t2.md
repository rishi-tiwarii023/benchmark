Added a health check endpoint that returns a simple JSON response indicating the API is healthy.

```python

def health_check():

```

**Endpoint Details:**
- **Method:** GET
- **Path:** /health
- **Response:** `{"status": "healthy"}`
- **Status Code:** 200
