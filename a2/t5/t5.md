# Changes Summary

## Improved Task Input Validation

### Files Modified

#### 1. app/schemas/task.py
Enhanced validation rules for TaskCreate and TaskUpdate schemas to enforce stricter input constraints.

**TaskCreate Schema:**
```python
class TaskCreate(BaseModel):
    title: str = Field(..., min_length=1, max_length=100)
    description: str | None = Field(None, max_length=500)
    status: str = Field("pending", pattern="^(pending|in_progress|done)$")
    priority: str = Field("medium", pattern="^(low|medium|high)$")
```

**TaskUpdate Schema:**
```python
class TaskUpdate(BaseModel):
    title: str | None = Field(None, min_length=1, max_length=100)
    description: str | None = Field(None, max_length=500)
    status: str | None = Field(None, pattern="^(pending|in_progress|done)$")
    priority: str | None = Field(None, pattern="^(low|medium|high)$")
```

**Validation Rules:**

| Field | Requirement | Validation |
|-------|-------------|-----------|
| title | Required | min_length=1, max_length=100 |
| description | Optional | max_length=500 |
| status | Optional (default: "pending") | Pattern: pending\|in_progress\|done |
| priority | Optional (default: "medium") | Pattern: low\|medium\|high |

**Error Response:**
All validation failures return HTTP 422 (Unprocessable Entity) with detailed error messages from Pydantic.

#### 2. tests/test_tasks_api.py
Added 13 comprehensive validation tests covering valid and invalid inputs.

**Valid Input Tests:**
- `test_valid_task_creation()` — Full task with all valid fields
- `test_title_max_length_valid()` — Title with exactly 100 characters
- `test_description_max_length_valid()` — Description with exactly 500 characters
- `test_valid_status_values()` — All three valid status values (pending, in_progress, done)
- `test_valid_priority_values()` — All three valid priority values (low, medium, high)
- `test_update_with_valid_values()` — PATCH with valid field updates

**Invalid Input Tests:**
- `test_empty_title_invalid()` — Empty title rejected (422)
- `test_title_too_long_invalid()` — Title > 100 characters rejected (422)
- `test_description_too_long_invalid()` — Description > 500 characters rejected (422)
- `test_invalid_status_value()` — Unsupported status value rejected (422)
- `test_invalid_priority_value()` — Unsupported priority value rejected (422)
- `test_update_with_invalid_title()` — PATCH with empty title rejected (422)
- `test_update_with_invalid_status()` — PATCH with invalid status rejected (422)

### Supported Values

**Status Values (mutually exclusive):**
- `pending` — Task not yet started
- `in_progress` — Task currently being worked on
- `done` — Task completed

**Priority Values (mutually exclusive):**
- `low` — Low priority task
- `medium` — Medium priority task (default)
- `high` — High priority task

### Example Validation Responses

**Valid Request:**
```json
POST /tasks
{
  "title": "Complete project",
  "description": "Finish the REST API implementation",
  "status": "in_progress",
  "priority": "high"
}
→ 201 Created
```

**Invalid Request (empty title):**
```json
POST /tasks
{
  "title": "",
  "status": "pending"
}
→ 422 Unprocessable Entity
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "title"],
      "msg": "String should have at least 1 character",
      "input": ""
    }
  ]
}
```
