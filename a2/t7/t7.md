#### 2. app/services/task.py
Updated the `list_tasks()` function to support pagination with filtering.

```python
def list_tasks(
    db: Session,
    status: str | None = None,
    priority: str | None = None,
    limit: int = 20,
    offset: int = 0,
) -> list[Task]:
    query = db.query(Task)
    if status:
        query = query.filter(Task.status == status)
    if priority:
        query = query.filter(Task.priority == priority)
    return query.order_by(Task.id).limit(limit).offset(offset).all()
```

### Pagination Features

**Query Parameters:**
- `limit` — Number of tasks to return (1-100, default: 20)
- `offset` — Number of tasks to skip (default: 0)

**Example Usage:**

```
GET /tasks                          → Returns first 20 tasks (default)
GET /tasks?limit=10                 → Returns first 10 tasks
GET /tasks?limit=10&offset=20       → Returns tasks 20-29
GET /tasks?status=pending&limit=5   → Returns first 5 pending tasks
```

**Validation Examples:**

```
GET /tasks?limit=0                  → 422 Unprocessable Entity (too small)
GET /tasks?limit=101                → 422 Unprocessable Entity (exceeds max)
GET /tasks?offset=-1                → 422 Unprocessable Entity (negative)
```

### Database Query Optimization

The pagination is implemented using SQLAlchemy's `.limit()` and `.offset()` methods, which translate to SQL LIMIT and OFFSET clauses for efficient database queries:

```sql
SELECT * FROM tasks 
WHERE status = ? AND priority = ?
ORDER BY id
LIMIT 20 OFFSET 0
```
